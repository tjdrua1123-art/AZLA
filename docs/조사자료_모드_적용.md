# 제공된 공개 EQ 조사 자료의 모드 적용 — 2026-11-11

사용자가 제공한 「10밴드 EQ 재조사 — 실제 공개 설정값과 원문 링크」의 A·E·F·H를 선택했습니다. 원본에 Q가 없는 경우 현재 앱의 PEAK·Q 1.4를 유지하므로 **원본 처리기와 동일한 응답이나 청감으로 검증한 것은 아닙니다.** 합성 +6 dB 보류는 다시 넣지 않고, 수동 조절 범위와 저장·미리듣기 분리는 유지합니다.

게인 단위는 dB입니다. 모든 필터는 PEAK·Q 1.4입니다. 기본 모드는 기존 32·63·125·250·500·1000·2000·4000·8000·16000 Hz와 0 dB를 유지합니다.

## 선택 이유와 출처

- **FPS — 자료 A:** 사용자가 우선 참고로 표시한 [PUBG 인벤 원문](https://www.inven.co.kr/board/battlegrounds/5074/3366)의 10개 게인과 일치함을 확인했습니다. 개인 사용자의 사운드카드/게임 경험이며 보편적인 성능 검증은 아닙니다. 발소리와 총성·다른 효과음도 함께 바뀝니다.
- **보컬 — 자료 E:** [ProMedia Vocal Clarity](https://pro-media.io/audio-equalizer/)의 공개 게인을 확인했습니다. 팟캐스트 중심인 자료 D보다 노래 감상용 목적에 가깝고, 저역 감쇄와 1–4 kHz 강조가 명확하여 선택했습니다.
- **밸런스 — 자료 F:** 같은 [ProMedia 공개 표](https://pro-media.io/audio-equalizer/)의 Loudness 곡선입니다. 기본 모드와 차이를 주는 저고역 강조이며 중립 보정이나 원음 복원을 의미하지 않습니다.
- **영화 — 자료 H:** [Reev Immersive 공개 표](https://reevmusic.world/vibes/immersive)의 게인을 확인했습니다. 저음만 강조하는 자료 I보다 저음과 고역 효과음을 함께 강조하는 감상용 목적에 맞아 선택했습니다. EQ만으로 공간 음향을 생성하지 않습니다.

자료 B는 재인용·특정 사운드카드 조건이고, C는 필터 종류·주파수·Q가 현재의 10밴드 구성과 달라 직접 혼합하지 않았습니다. R&B인 G는 장르 특화 목적이므로 범용 음악 밸런스에 섞지 않았습니다. 값을 임의 평균하거나 이전의 밴드별 최대 +5 dB에 맞춰 축소하지 않았습니다.

## 소프트웨어 검증과 실제 출력의 차이

원본 SDK의 정수 계수로 20 Hz–20 kHz, 65,537개 지점의 최종·순차 누적 응답을 계산했습니다. 합성 최대는 FPS 약 +17.682 dB, 보컬 +5.175 dB, 밸런스 +7.056 dB, 영화 +9.873 dB입니다. 수치와 곡선은 `preset-response-audit.json`, `preset-response-curves.csv`, 입력값은 `사운드_모드_시작값.json`에 기록합니다.

ProMedia는 헤드룸·리미터를, Reev Immersive는 -2 dB 프리앰프와 리미터를 명시합니다. 현재 앱은 해당 처리를 구현하지 않으므로 **공개 게인을 적용했다고 같은 클리핑 보호가 생기지 않습니다.** DAC 볼륨을 충분히 낮춘 뒤 청음·측정으로 확정해야 합니다. 실제 기기 청음·출력 측정은 이 환경에서 하지 않았으며, 각 밴드 +5 dB 시험이 FPS의 +12 dB 밴드를 보증하지 않습니다.

`npm test`, `node scripts/analyze-presets.mjs`, `python tests/browser_smoke.py`, `python tests/browser_saved_settings.py`로 검증합니다. 이전에 저장한 사용자 설정은 자동 변경하지 않습니다.
