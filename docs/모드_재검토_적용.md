# 모드 재검토안 적용 — 2026-11-11

사용자에게 제시하고 승인받은 재검토 보고서·비교 그래프의 설정을 적용했습니다. 공개 게인을 일괄 비례 조정하는 단계에서 한 번 더 검토하여 **현재의 전체 PEAK 필터 구조에서 모드별 목적 대역의 대비를 다듬은 자체 조정값**입니다. 실기 청음이나 최적값 검증을 완료했다는 의미는 아닙니다.

모든 용도별 모드는 최고 밴드 +6 dB, PEAK·Q 1.4를 유지합니다. 합성 응답 +6 dB 제한은 넣지 않습니다. 기본 모드와 이전 사용자 저장 기록도 유지합니다.

| 주파수 (FPS·보컬·밸런스 / 영화) | FPS | 보컬 | 밸런스 | 영화 |
|---|---:|---:|---:|---:|
| 31 / 32 Hz | -2 | -3 | 4 | 6 |
| 62 / 64 Hz | -1 | -2 | 6 | 5 |
| 125 Hz | 1.5 | -1 | 2 | 2.5 |
| 250 Hz | 0 | 0 | 0 | 0 |
| 500 Hz | -1 | 1 | 0 | -1 |
| 1 kHz | 3 | 3 | 0 | 0 |
| 2 kHz | 5 | 6 | 1 | 2 |
| 4 kHz | 6 | 3 | 2 | 3 |

| 16 kHz | 0 | 0 | 2 | 1.5 |

게인 단위는 dB입니다. 기본 모드는 기존 32·63 Hz로 시작하며 전체 0 dB입니다.

## 변경 이유

- **FPS:** 이전에는 500 Hz 합성이 약 +4.85 dB이고 1–4 kHz가 넓게 약 +8 dB였습니다. 이번에는 125 Hz의 발걸음 몸통을 남기고 250–500 Hz 및 1 kHz의 광범위 증폭을 줄여 2–4 kHz를 상대적으로 강조합니다. 발소리 탐지 성능을 실측한 결과로 주장하지 않습니다.
- **보컬:** 이전 31·63 Hz의 합성이 약 -6.95/-6.14 dB였습니다. 저역 감쇄와 1·4 kHz 상승을 완화하고 2 kHz 중심의 명료도를 유지하여 두께와 듣기 편한 정도를 비교하기 위한 값입니다.
- **음악 밸런스:** 기존 Loudness형의 중역 감쇄를 없애고 16 kHz 강조를 줄였습니다. 저역 중심을 63 Hz로 옮겨 음악의 탄력을 강조한 감상용이며 중립 보정은 아닙니다.
- **영화:** 31–125 Hz의 충격감을 남기고 기존에 합성 약 +7 dB이던 8–16 kHz를 완화했습니다. 1–2 kHz를 보완해 대사와 효과음의 균형을 비교합니다. 공간 음향 처리를 추가한 것은 아닙니다.

## 출처를 참고한 범위

[ProMedia](https://pro-media.io/audio-equalizer/)는 양 끝 밴드를 셸프로 처리하고 출력 감쇄·리미터를 사용한다고 설명합니다. [Reev Immersive](https://reevmusic.world/vibes/immersive)도 프리앰프와 리미터를 사용합니다. 따라서 그 숫자의 비율만 옮기면 우리 전체 PEAK 구조에서 같은 응답이 되지 않습니다. [DoveSonic의 게임별 EQ](https://dovesonic.com/guides/valorant-audio-settings-eq-guide)도 대역마다 다른 Q와 필터를 쓰므로 현재 값의 직접 원본이나 성능 검증으로 주장하지 않습니다.

현재 값은 제공 자료를 참고한 뒤 앱 구조에 맞게 재검토한 자체 조정값입니다. 원문과 같은 리미터·프리앰프 보호는 구현하지 않습니다.

## 검증

수정하지 않은 SDK의 96 kHz 계수로 65,537개 주파수 지점에서 계산했습니다. 합성 최대는 FPS 약 +7.581 dB, 보컬 +7.161 dB, 밸런스 +7.122 dB, 영화 +7.081 dB입니다. 합성값을 특정 상한에 맞춘 설계는 아닙니다.

`npm test`, `node scripts/analyze-presets.mjs`, `tests/browser_smoke.py`, `tests/browser_live_preview.py`, `tests/browser_saved_settings.py`로 입력·계산·미리듣기·명시적 저장·저장값 복원을 검증합니다. 실제 소리와 왜곡은 같은 기기·장착·체감 음량으로 원본/이전/새 설정을 비교하고 측정해야 합니다. 이전에 저장한 값은 자동 변경하지 않으므로 새 값을 쓰려면 모드를 다시 선택해야 합니다.
