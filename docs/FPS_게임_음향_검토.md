# FPS 모드: PUBG·VALORANT 기준 검토

검토일: 2026-11-10. PC판 두 게임을 대상으로 하나의 FPS 모드를 구성합니다. UI 이름은 기존 FPS 모드를 유지합니다. 음악·영화·기본 모드의 값은 이번 검토에서 변경하지 않습니다.

## 근거의 구분

이전 FPS는 일반 명료도 대역을 게임에 응용한 설계였습니다. 이번에는 게임별 자료를 구분해 검토하고, 아래 공개 게임 분석에서 제시된 대역을 참고합니다. **원본 게임 음원을 직접 녹음·FFT 분석한 결과가 아니며, 공식 권장 EQ나 두 게임의 검증된 최적값도 아닙니다.**

## 10밴드에 적용한 설계 판단

두 게임의 공개 분석에서 공통으로 언급하는 낮은 타격 성분과 1–4 kHz의 세부 성분을 함께 다룹니다. VALORANT 분석에서 언급한 상부 세부 성분도 조절할 수 있도록 FPS의 9번째 밴드만 8 kHz에서 6 kHz로 변경합니다. 나머지 모드는 8 kHz를 유지합니다.

| 중심 주파수 | 게인 | 설계 의도 |
|---|---:|---|
| 32 Hz | −4 dB | 극저역의 비중을 분명히 낮춤 |
| 63 Hz | −4 dB | 저역의 울림을 정리함 |
| 125 Hz | +3 dB | 두 게임의 낮은 발걸음 성분과 목재 등 저역의 비중을 보완 |
| 250 Hz | 0 dB | 낮은 발걸음의 몸통을 과하게 깎지 않음 |
| 500 Hz | −2 dB | PUBG 공개 분석의 350–450 Hz 부근을 넓게 소폭 정리 |
| 1 kHz | +3 dB | 중역 존재감과 표면 질감을 보완 |
| 2 kHz | +3 dB | 두 게임 분석에서 공통으로 언급하는 세부 대역 보완 |
| 4 kHz | +4 dB | PUBG 약 4.1 kHz 및 VALORANT 상중역을 보완 |
| 6 kHz | +2 dB | VALORANT 약 4.6–6.2 kHz 세부 대역 보완 |
| 16 kHz | 0 dB | 불필요한 초고역 부스트 추가 없음 |

모든 밴드는 **PEAK, Q 1.4**입니다. 주파수와 게인은 두 게임을 함께 겨냥해 선택한 자체 조정값이며, 공개 자료에서 제시한 그대로의 설정이 아닙니다. 더 넓은 Q 1.4에서는 인접 필터가 겹치므로, 원문에 있는 좁은 Q의 +5~6 dB를 그대로 넣지 않았습니다. 음성 명료도 자료는 이 FPS 설정의 수치 근거로 사용하지 않습니다.

저역을 더 반영하라는 요청에 따라 32/63 Hz를 각각 −4 dB, 125 Hz를 +3 dB, 500 Hz를 −2 dB로 강화했습니다. 모든 필터는 PEAK이며, 자료의 55 Hz LOW SHELF −12 dB를 재현한 곡선이라는 의미는 아닙니다. PEAK 제약 안에서 저역 대비를 키운 자체 설계입니다.

## 검증과 남은 확인

SDK에서 계산한 FPS 합성 최소/최대는 약 −4.70/+5.48 dB입니다. 각 밴드 값이 아니라 모든 필터를 합친 응답이며, 약 0.52 dB의 안내 기준 여유를 둡니다.

SDK의 20 Hz–20 kHz 합성 응답과 모든 누적 필터 단계는 +5.5 dB 이하로 제한합니다. `node scripts/analyze-presets.mjs`가 실제 FPS 값으로 계산하고 [감사 결과](preset-response-audit.json)를 생성합니다. 브라우저·모의 HID로 6 kHz 표시, 모드 전환·되돌리기, 안내창 없는 저장 명령 전송을 검증합니다.

이는 게임의 발소리 검출률·방향 판별률·실제 DAC의 클리핑을 시험한 결과가 아닙니다. 총성·능력음·음성도 같은 대역에서 함께 올라갈 수 있습니다. 원본 게임 녹음에 대해 재질·거리·방향·게임 설정별 발소리와 방해음을 비교하고, 실제 이어폰으로 음량을 맞춰 평가해야 효과를 확정할 수 있습니다. PUBG PC와 PUBG Mobile 자료를 섞지 않았습니다.
