# 밴드별 기준 모드 설정 — 2026-11-11

사용자가 각 밴드를 +5 dB로 설정한 조건에서 왜곡이 없었다고 확인했습니다. 이는 **합성 응답 +5 dB 제한**과 다릅니다. 따라서 앱에서 임의로 정했던 합성 +6 dB 보류·확인 조건을 제거하고 합성 응답을 참고 정보로만 표시합니다.

기본 프리셋은 음색 비율을 보존하면서 각 모드의 가장 큰 밴드를 +5 dB로 맞췄습니다. 수동 입력은 기존 ±12 dB이며, +5 dB가 새 입력 상한은 아닙니다. 모든 필터는 PEAK·Q 1.4입니다.

게인 단위는 dB입니다.

FPS는 제공 이미지의 게인 ×0.5, 보컬은 이전 게인 ×1.25, 밸런스는 ×5/3, 영화는 ×10/9를 0.1 dB로 반올림했습니다. FPS 이미지에 없는 16 kHz는 0 dB입니다. 기본 모드는 그대로입니다.

수정하지 않은 SDK의 정수 계수로 65,537개 주파수 지점에서 계산한 합성 최대는 FPS 약 +6.474 dB, 보컬 +6.167 dB, 밸런스 +5.966 dB, 영화 +6.059 dB입니다. 이는 소프트웨어 계산값이며 실제 음향 측정이나 클리핑 판정이 아닙니다. 전체 게인을 자동 감쇄하지 않습니다.

DAC 출력이 강할 수 있으므로 화면에 볼륨 주의 문구를 상시 표시합니다. 사용자의 시험 결과가 모든 음원·기기·음량에서 클리핑이 없음을 보증하지는 않습니다. 미리듣기와 명시적 저장의 분리는 유지하며 과거에 저장한 값은 자동 변경하지 않습니다.
