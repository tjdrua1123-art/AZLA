# AZLA Equalizer 출시 전 검증

현재 소프트웨어·원본 SDK 검증과 남은 실기 검증을 구분합니다. 기존 프로그램의 사용자 Flash 저장 성공 이력을 새 버전 실기 결과로 대신 기록하지 않습니다.

## 원본 SDK·연결

- [x] 최신 GitHub main의 SDK 본체 포함, 원본 해시 보존
- [x] 전역·생성자·CB 경로·Report 75 대조
- [x] 10개 36바이트 EQ, 7바이트 RAM, **3바이트 Flash** 확인
- [x] 동기 명령 생성, 순차 전송·대기, 원본 SDK + 모의 HID 검증
- [x] 기존 10개 VID 검색·선택, 출력 Report 75 확인
- [x] 잘못된 VID/인터페이스 차단
- [x] 읽기 전용 EQ Tag 요청·응답, 타임아웃, 마지막 Flash 전송값 대조 모의 검증
- [ ] 최종 제품 VID/PID·펌웨어·descriptor 확정
- [ ] 출하용 registered 모드 사용 시 제품 조합 등록 및 실기 확인
- [ ] 비지원 제품·펌웨어 처리, SDK 배포 조건·제3자 고지 확정

## 실제 DAC 전송·보존

- [ ] 0dB 포함 10밴드 0~9 실제 수신
- [ ] 실제 Report ID·순서·명령 간격·Flash 대기시간
- [ ] 저장 1회당 Flash 1회, 편집·사운드 선택은 RAM에만 반영
- [ ] 실제 DAC에서 연속 조절 지연·팝 노이즈·변경 밴드만 전송하는 미리듣기 확인
- [ ] +6 dB 초과 미리듣기 확인·취소, 저장 전에는 전원 재연결 후 마지막 Flash 값 유지
- [ ] 30회 이상 반복 적용 및 로그 순환
- [ ] 더블클릭·편집·연결 변경 중 일관된 스냅샷
- [ ] 전송·RAM·Flash 전후 USB 분리 오류
- [ ] 오래된 명령이 새 연결 장치에 전달되지 않음
- [ ] **USB 전원 완전 차단·재연결 후 EQ 보존**
- [ ] 실제 기기의 Tag 응답과 현재 상태 표시 일치
- [ ] Tag 응답만으로 전체 EQ 영구 보존을 증명한다고 표시하지 않음

## 음향·사운드 라이브러리

- [ ] 초록·주황 원음 응답의 REW 원본 TXT/CSV와 측정·장착·음량 조건 확보
- [ ] 저역·중역·고역 단일 필터 중심 주파수·Q·부스트·컷 확인
- [ ] 합성 예상 응답과 EQ ON−OFF 실측 비교
- [ ] 지원 USB 입력 샘플레이트별 일관성
- [ ] DRC/리미터·클리핑·THD+N·채널 매칭·음량 변화 측정
- [ ] LS·HS·LP·HP 지원 범위, SDK HS 특이 응답 출하 전 판정
- [ ] 이미지 참고 사운드 라이브러리의 청음·음량 매칭·브랜드 승인
- [ ] FPS·음악 보컬·음악 밸런스·영화 모드별 목적과 청감 확인
- [ ] 고역 공진·깊은 골의 과도한 보정 없음

첨부 CB5100AU 데이터시트의 8밴드 표기와 본 제품의 제조사 확인 10밴드 동작은 최종 제품/펌웨어로 대조합니다. CB1300D로 임의 전환하지 않습니다. SDK 계산 96kHz와 실제 DSP 처리율도 구분합니다.
