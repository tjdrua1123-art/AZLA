AZLA Equalizer — 더 선명한 화이트·실버 UI와 새 10밴드 사운드 라이브러리를 적용한 원본 SDK 포함 검토용 빌드입니다.

이번 변경에서 첫 화면을 FLAT으로 맞추고 `PRESET` 모드 표시를 제거했습니다. 모든 기본 사운드는 같은 중심 주파수와 Q 0.75를 사용합니다. 제공된 초록·주황 원음 응답을 바탕으로 500–850Hz 골을 보완하고 3.1·8.5kHz 피크를 줄였으며, 각 사운드의 차이를 이전보다 분명하게 조정했습니다.

**Windows 실행 방법**

1. Assets에서 `AZLA-Equalizer-Windows.zip`을 받습니다.
2. ZIP 전체를 압축 해제하고 `AZLA Equalizer.exe`를 실행합니다. EXE만 따로 옮기지 마세요.
3. 기기 연결 → 본인의 AZLA DAC 선택 → 사운드 선택·조절 → EQ 적용을 누릅니다.

Python 또는 Node.js를 따로 설치할 필요가 없습니다.

EQ 적용은 원본 SDK의 10밴드/RAM/Flash 명령을 사용합니다. 실제 Flash 명령을 7바이트로 잘못 검사하던 오류를 3바이트 명령에 맞게 수정했습니다. SDK 원본은 변경하지 않았습니다.

45개 소프트웨어 검증과 원본 SDK + 모의 HID Flash 전송 검증은 통과했습니다. 새 버전의 실제 DAC 연결, 음향 응답 및 전원 차단 후 설정 보존은 별도 실기 검증 대상입니다. 완료 표시는 Flash 저장 명령 전송 완료를 뜻합니다. 사운드 라이브러리는 측정 이미지 참고 시작값입니다.

이 빌드는 코드 서명되지 않은 검토용이며 양산 출하 검증 완료본이 아닙니다.
