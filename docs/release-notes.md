AZLA Equalizer preview.4 — 새 7개 사운드 모드와 사용자 저장 제거를 적용한 원본 SDK 포함 검토용 빌드입니다.

**이번 변경**

- 10개 중심 대역을 `31 / 63 / 125 / 250 / 500 / 1k / 2k / 4k / 8k / 11kHz`로 재구성했습니다.
- 모든 기본 모드는 Q 0.75와 PEAK 필터를 사용합니다.
- 모드를 FLAT, PUBG 텍티컬, 발로란트, 발소리 극대화, 보컬 강조, 하만 밸런스, 시네마 영화로 교체했습니다.
- 제공된 초록·주황 측정 그래프와 모드별 조언을 반영하고, 필터 중첩 예상 최대 상승은 6dB 이내로 조정했습니다.
- 우측 사용자 저장, 저장 창, 가져오기·내보내기를 제거했습니다. 새 버전 첫 실행 시 v1~v4 사용자 저장 키를 삭제하며 매 실행 FLAT으로 시작합니다.
- 장치 문제 확인을 위한 설정의 **진단 기록 저장**은 유지합니다.

**Windows 실행 방법**

1. Assets에서 `AZLA-Equalizer-Windows.zip`을 받습니다.
2. ZIP 전체를 압축 해제하고 `AZLA Equalizer.exe`를 실행합니다. EXE만 따로 옮기지 마세요.
3. 기기 연결 → 본인의 AZLA DAC 선택 → 사운드 모드 선택·조절 → EQ 적용을 누릅니다.

Python 또는 Node.js를 따로 설치할 필요가 없습니다.

EQ 적용은 수정하지 않은 원본 SDK의 10밴드/RAM/Flash 명령을 사용합니다. 실제 Flash 명령은 `[1,1,0]` 3바이트이며, SDK 원본 해시는 유지했습니다.

39개 소프트웨어 검증과 Chromium의 원본 SDK + 모의 HID Flash 전송 검증은 통과했습니다. 새 버전의 실제 DAC 연결, 음향 응답 및 전원 차단 후 설정 보존은 별도 실기 검증 대상입니다. 완료 표시는 Flash 저장 명령 전송 완료를 뜻합니다.

이 빌드는 코드 서명되지 않은 검토용이며 양산 출하 검증 완료본이 아닙니다.
