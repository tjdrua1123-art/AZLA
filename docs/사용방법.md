# AZLA Equalizer 사용 방법

제조사 원본 SDK가 포함된 10밴드 EQ 프로그램입니다. 조절하면서 소리를 미리 듣고 **기기에 저장**을 누를 때만 Flash 저장 명령을 보냅니다.

## 실행

1. GitHub **Code → Download ZIP**으로 받은 파일을 폴더 전체로 압축 해제합니다.
2. `start_windows.bat`를 실행합니다. 기존 프로그램의 Python 3 환경을 그대로 쓸 수 있고, Python이 없으면 설치된 Node.js를 사용합니다.
3. Windows Chrome 또는 Edge에서 `http://localhost:8768`을 엽니다.
4. 서버 창은 사용 중 열어 둡니다. 이전 서버는 종료하고, 이전 화면이 남으면 `Ctrl+Shift+R`로 새로고침합니다.

직접 실행하려면 프로젝트 폴더에서 설치된 도구에 맞는 명령 하나를 사용합니다.

```powershell
py -3 -m http.server 8768 --bind 127.0.0.1
```

```powershell
node server.mjs
```

Windows 앱 폴더를 받았다면 전체 압축을 풀고 `AZLA Equalizer.exe`를 실행합니다. EXE만 옮기면 실행되지 않습니다. 패키징한 앱에는 Python·Node.js 설치가 필요 없습니다.

## 미리듣기와 기기 저장

1. DAC를 USB로 연결하고 **기기 연결**을 누릅니다.
2. 선택 창에서 본인의 AZLA DAC EQ 인터페이스를 선택합니다. 기존 프로그램과 같은 제조사 검색을 사용하므로 PID를 직접 입력하지 않습니다.
3. 기본 모드 위의 **저장된 설정**을 누르면 이 프로그램에서 마지막으로 저장한 10밴드 설정을 불러옵니다. 저장 기록이 없으면 안내가 표시됩니다.
4. 매 실행 시 편집 화면은 **기본 모드**으로 시작합니다. 왼쪽 사운드 모드나 10개 슬라이더로 조절하고, 주파수를 입력하거나 그래프의 점을 드래그할 수 있습니다.
5. **세부 조절**을 켜면 Q와 필터가 표시됩니다. 5개 기본 모드의 Q는 모두 1.4입니다.
6. 볼륨을 낮추고 EQ를 조절하면 RAM에 임시 반영되어 소리를 미리 들을 수 있습니다. ‘미리듣기 반영 중’이 끝나면 ‘미리듣기 중 · 저장 전’으로 표시됩니다.
7. 소리를 확인한 뒤 **기기에 저장**을 누릅니다. 진행 중인 미리듣기가 끝난 뒤 버튼을 누른 시점의 설정을 저장합니다. 저장 중 중복 저장과 편집은 잠깁니다.
8. **설정 전송 완료**를 확인합니다. 새 버전의 실제 보존은 전원 분리·재연결 후 청음 또는 계측으로 확인합니다.

편집과 모드 선택은 RAM에만 쓰며 Flash에는 저장하지 않습니다. 빠른 연속 조절은 최신 값으로 모아서 순차 전송합니다. 첫 미리듣기는 10밴드 전체를 보내고 이후에는 변경된 밴드와 RAM 반영 명령만 보냅니다. USB 전송 때문에 반영에 짧은 지연이 있을 수 있습니다.

**기기에 저장** 1회마다 10밴드 전체, RAM 반영, 필요한 대기, Flash 명령 1개를 보냅니다. 새로고침·화면 종료·연결 해제로 자동 저장하지 않습니다. 브라우저를 닫는 것만으로 RAM이 초기화되는 것은 아니며, 미저장 상태는 기기 전원 재연결 후 확인하세요.

예상 최대 상승이 +6 dB를 넘으면 새 설정의 자동 미리듣기를 보류합니다. 볼륨을 낮추고 **볼륨 확인 후 미리듣기 → 확인 후 미리듣기**를 누르면 현재 값만 RAM에 반영합니다. 값을 다시 바꾸면 다시 확인이 필요합니다. **기기에 저장**은 별도 동작입니다. 이 기준은 앱 안내 기준이며 실제 클리핑이 없음을 보장하지 않습니다.

### 저장된 설정

- **기기에 저장**을 완료한 마지막 설정을 별도로 보관합니다. 수동 조절이나 모드 미리듣기로 이 기록이 바뀌지 않습니다.
- **저장된 설정**을 누르면 마지막 저장값을 편집 화면으로 불러오고, 기기가 연결되어 있으면 소리를 미리 들을 수 있습니다. 불러오기만으로 다시 저장하지 않습니다.
- 저장 기록이 없는 경우에는 기본 모드를 대신 불러오지 않습니다. 기기를 연결하고 원하는 설정을 먼저 저장해 주세요.
- 같은 브라우저에서는 새로고침 후에도 불러올 수 있습니다. 다른 브라우저나 기록을 지운 환경에서는 이전 설정을 불러올 수 없습니다.
- 연결된 기기의 식별 정보가 저장 기록과 다르면 불러오지 않습니다. 기기에서 10밴드 전체를 읽는 기능은 없으므로, 이 프로그램에서 마지막으로 저장한 기록을 사용합니다.

## 사운드 모드와 측정

- 기본 모드는 **기본 모드, FPS 모드, 음악 보컬, 음악 밸런스, 영화**입니다.
- 기본·음악·영화 모드의 주파수는 **32·63·125·250·500 Hz, 1·2·4·8·16 kHz**이며 Q 1.4와 PEAK 필터로 시작합니다. 32 Hz는 명목 31.5 Hz의 정수 근사입니다.
- 사용자 사운드 저장·가져오기·내보내기는 제공하지 않습니다. 수동 조절은 현재 실행 중에만 유지되며 다시 실행하면 기본 모드로 돌아갑니다.
- 새 버전 첫 실행 시 `azla_equalizer_v4/v3`과 기존 v1·v2 사용자 프리셋·마지막 EQ 저장 키를 삭제합니다.
- 연결 오류 시 표시되는 진단 창의 **REW 측정 비교**에 같은 장착·음량 조건의 OFF·ON TXT/CSV를 불러옵니다. 첫 두 열은 주파수 Hz, SPL dB여야 하며 외부 업로드는 하지 않습니다.
- 네 가지 용도별 모드는 공개 음향 자료와 첨부 제안서를 검토한 자체 설계값입니다. FPS의 저음 감쇄는 깊게 하지 않고, 각 모드의 효과음·보컬·음악 저고역·영화 저음 대역을 강조했습니다. [상세 게인·근거·한계](사운드_라이브러리_튜닝.md)를 확인하세요. 수동 조절 범위는 기존 ±12 dB입니다. 사용하는 이어폰에 맞게 조절하세요.
- 양의 게인이 겹치면 클리핑이 생길 수 있습니다. 기본 프리셋은 예상 상승이 6 dB 아래로 머물도록 조정했습니다. 수동 조절 후 예상 상승이 6 dB를 넘으면 미리듣기와 저장 전에 볼륨을 확인합니다. DAC 출력이 강해 소리가 크게 들릴 수 있습니다. 앱은 전체 DAC 출력을 자동으로 바꾸지 않습니다.
- HIGH SHELF는 고역을 조절하는 필터입니다. 5개 기본 모드는 PEAK만 사용하며 제조사 SDK는 원본 그대로 사용합니다.

## 문제가 발생하면

| 증상 | 확인할 내용 |
|---|---|
| 장치가 보이지 않음 | USB 연결, Chrome/Edge, 다른 EQ 앱 종료 후 재시도 |
| EQ 인터페이스가 아니라는 안내 | DAC의 출력 Report 75 인터페이스 선택 |
| 적용 오류 | USB 확인 후 기기 재연결·재시도 |
| 전송 후 변화 없음 | Windows 출력 장치, 올바른 DAC, 같은 조건의 OFF/ON 측정 |
| 재연결 후 설정 사라짐 | 연결 오류 시 표시되는 진단 창에서 기록 저장 후 펌웨어·측정 정보와 함께 확인 |
| 이전 화면/포트 사용 중 | 이전 서버 종료 후 재실행·새로고침 |

연결 오류 시 표시되는 진단 창의 **연결된 장치 확인**은 이름과 VID/PID만 읽습니다. **기록 저장**은 사용자 사운드 저장과 별개이며, 문제 확인을 위한 식별 정보와 전송 기록만 내보냅니다.

## 개발자 연결 설정

기본 `device-config.json`의 `connectionMode: "manufacturer"`는 기존 10개 제조사 VID 검색을 사용합니다. 출력 Report 75를 확인하고 사용자 선택 장치에 기록합니다. 본인의 AZLA CB 계열 DAC를 선택해야 하며 검색 목록이 모든 제품의 호환성을 보증하지는 않습니다.

최종 출하 제품을 고정하려면 `connectionMode: "registered"`와 `devices`의 정확한 VID/PID 조합을 사용합니다. 일반 사용자가 PID를 입력할 필요는 없습니다.

개발·패키징 명령은 `npm ci`, `npm run desktop`, `npm run package:folder` 또는 `npm run package:win`입니다. Windows 실행·설치·서명은 별도 검증합니다.

FPS는 PUBG·VALORANT의 공개 게임 음향 분석을 참고해 125 Hz를 보강하고 9번째 대역을 8 kHz에서 6 kHz로 변경했습니다. 실제 게임 녹음으로 확정한 최적값은 아니며, 자세한 근거는 docs/FPS_게임_음향_검토.md에 기록했습니다.
