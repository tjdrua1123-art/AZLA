# AZLA Equalizer 사용 방법

제조사 원본 SDK가 포함된 10밴드 EQ 프로그램입니다. **EQ 적용**을 누르면 현재 설정을 Flash에 기록하는 명령까지 보냅니다.

## 실행

1. GitHub **Code → Download ZIP**으로 받은 파일을 폴더 전체로 압축 해제합니다.
2. `start_windows.bat`를 실행합니다. 기존 프로그램의 Python 3 환경을 그대로 쓸 수 있고, Python이 없으면 설치된 Node.js를 사용합니다.
3. Windows Chrome 또는 Edge에서 `http://localhost:8768`을 엽니다.
4. 서버 창은 사용 중 열어 둡니다. 이전 서버는 종료하고, 이전 화면이 남으면 `Ctrl+Shift+R`로 새로고침합니다.

직접 실행하려면 프로젝트 폴더에서 설치된 도구에 맞는 명령 하나를 사용합니다.

```powershell
py -3 -m http.server 8768 --bind 127.0.0.1
```

```powershell
node server.mjs
```

Windows 앱 폴더를 받았다면 전체 압축을 풀고 `AZLA Equalizer.exe`를 실행합니다. EXE만 옮기면 실행되지 않습니다. 패키징한 앱에는 Python·Node.js 설치가 필요 없습니다.

## EQ 적용

1. DAC를 USB로 연결하고 **기기 연결**을 누릅니다.
2. 선택 창에서 본인의 AZLA DAC EQ 인터페이스를 선택합니다. 기존 프로그램과 같은 제조사 검색을 사용하므로 PID를 직접 입력하지 않습니다.
3. 매 실행 시 **FLAT**이 선택됩니다. 왼쪽 사운드 모드나 10개 슬라이더로 조절하고, 주파수를 입력하거나 그래프의 점을 드래그할 수 있습니다.
4. **세부 조절**을 켜면 Q와 필터가 표시됩니다. 7개 기본 모드의 Q는 모두 0.75입니다.
5. **EQ 적용**을 누르고 완료될 때까지 USB를 연결해 둡니다. 전송 중 중복 적용과 편집은 잠깁니다.
6. **Flash 저장 명령 전송 완료**를 확인합니다. 새 버전의 실제 보존은 전원 분리·재연결 후 청음 또는 계측으로 확인합니다.

편집 중에는 자동으로 기기에 쓰지 않습니다. 적용 1회마다 10밴드 전체, RAM 반영, 필요한 대기, Flash 명령 1개를 보냅니다. 기기에 여러 사운드를 동시에 저장하지 않고 마지막으로 적용한 설정 1개를 기록합니다.

## 사운드 모드와 측정

- 기본 모드는 **FLAT, PUBG 텍티컬, 발로란트, 발소리 극대화, 보컬 강조, 하만 밸런스, 시네마 영화**입니다.
- 공통 중심 주파수는 **31·63·125·250·500 Hz, 1·2·4·8·11 kHz**이며 모두 Q 0.75와 PEAK 필터로 시작합니다.
- 사용자 사운드 저장·가져오기·내보내기는 제공하지 않습니다. 수동 조절은 현재 실행 중에만 유지되며 다시 실행하면 FLAT으로 돌아갑니다.
- 새 버전 첫 실행 시 `azla_equalizer_v4/v3`과 기존 v1·v2 사용자 프리셋·마지막 EQ 저장 키를 삭제합니다.
- 설정의 **REW 측정 비교**에 같은 장착·음량 조건의 OFF·ON TXT/CSV를 불러옵니다. 첫 두 열은 주파수 Hz, SPL dB여야 하며 외부 업로드는 하지 않습니다.
- 기본 모드는 제공된 초록·주황 원음 응답과 모드별 튜닝 조언을 반영한 시작값입니다. 필터 중첩을 계산해 예상 최대 상승을 6dB 이내로 제한했으며, 최종 튜닝은 같은 조건의 실측과 청음으로 확정합니다.
- 양의 게인이 겹치면 클리핑이 생길 수 있습니다. 앱은 중첩 예상 게인을 표시하며 전체 DAC 출력을 자동으로 바꾸지 않습니다.
- HIGH SHELF는 SDK 계수의 특이 동작이 확인되어 실험용입니다. 7개 기본 모드는 PEAK만 사용합니다.

## 문제가 발생하면

| 증상 | 확인할 내용 |
|---|---|
| 장치가 보이지 않음 | USB 연결, Chrome/Edge, 다른 EQ 앱 종료 후 재시도 |
| EQ 인터페이스가 아니라는 안내 | DAC의 출력 Report 75 인터페이스 선택 |
| 적용 오류 | USB 확인 후 기기 재연결·재시도 |
| 전송 후 변화 없음 | Windows 출력 장치, 올바른 DAC, 같은 조건의 OFF/ON 측정 |
| 재연결 후 설정 사라짐 | 설정에서 진단 기록 저장 후 펌웨어·측정 정보와 함께 확인 |
| 이전 화면/포트 사용 중 | 이전 서버 종료 후 재실행·새로고침 |

설정의 **연결된 장치 확인**은 이름과 VID/PID만 읽습니다. **기록 저장**은 사용자 사운드 저장과 별개이며, 문제 확인을 위한 식별 정보와 전송 기록만 내보냅니다.

## 개발자 연결 설정

기본 `device-config.json`의 `connectionMode: "manufacturer"`는 기존 10개 제조사 VID 검색을 사용합니다. 출력 Report 75를 확인하고 사용자 선택 장치에 기록합니다. 본인의 AZLA CB 계열 DAC를 선택해야 하며 검색 목록이 모든 제품의 호환성을 보증하지는 않습니다.

최종 출하 제품을 고정하려면 `connectionMode: "registered"`와 `devices`의 정확한 VID/PID 조합을 사용합니다. 일반 사용자가 PID를 입력할 필요는 없습니다.

개발·패키징 명령은 `npm ci`, `npm run desktop`, `npm run package:folder` 또는 `npm run package:win`입니다. Windows 실행·설치·서명은 별도 검증합니다.
