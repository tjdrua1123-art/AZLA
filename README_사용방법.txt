AZLA Equalizer 2.0 — 화이트·실버

[GitHub에서 받은 소스 실행]
1. Code > Download ZIP으로 내려받고 폴더 전체를 압축 해제합니다.
2. start_windows.bat를 실행합니다.
   기존 프로그램을 실행하던 Python 3을 그대로 사용할 수 있습니다.
   Python이 없으면 설치된 Node.js를 사용합니다.
3. Windows Chrome 또는 Edge에서 http://localhost:8768을 엽니다.
4. 기기 연결 > 본인의 AZLA DAC 선택 > 볼륨 낮추기 > 사운드 선택·조절하며 미리듣기 > 기기에 저장 순서로 사용합니다.
서버 창은 사용 중 열어 두고 이전 버전 서버는 먼저 종료하세요.

[Windows 앱 폴더를 받은 경우]
전체 압축을 풀고 AZLA Equalizer.exe를 실행합니다.
EXE만 옮기지 마세요. 같은 폴더의 DLL과 resources 등이 필요합니다.
패키징한 앱에는 Python이나 Node.js를 별도로 설치하지 않습니다.

[EQ 저장]
기존 프로그램의 제조사 SDK를 포함했습니다.
슬라이더·수치·그래프·모드를 바꾸면 RAM에만 임시 반영해 소리를 미리 들을 수 있습니다.
기기에 저장을 눌러야 10밴드 전체, RAM 반영, Flash 저장 명령을 순서대로 전송합니다.
연결·조절·화면 종료만으로 Flash에 자동 저장하지 않습니다.
큰 증폭(+6 dB 초과)은 볼륨 확인 후 미리듣기를 눌러 확인해야 반영합니다. 이 확인은 Flash 저장이 아닙니다.
미리듣기 중에는 계속 조절할 수 있으며, 저장할 때는 진행 중인 미리듣기가 끝나기를 기다립니다.
저장 중 USB를 분리하지 마세요. 완료 표시는 설정 전송 완료입니다.
새 버전의 실제 보존은 USB 전원 차단·재연결 후 청음/계측으로 확인해야 합니다.

[저장된 설정]
기본 모드 위의 저장된 설정을 누르면 이 프로그램에서 마지막으로 저장한 EQ를 불러옵니다.
미리듣기나 모드 변경은 마지막 저장 기록을 바꾸지 않습니다.
연결 중 불러온 값은 소리를 미리 들을 수 있으며 기기에 저장을 눌러야 다시 저장됩니다.
같은 브라우저에서는 새로고침 후에도 저장 기록을 불러올 수 있습니다.
저장 기록이 없거나 연결된 기기가 다르면 안내를 표시합니다.
기기에서 모든 조절값을 직접 읽는 기능은 없어 이 프로그램의 마지막 저장 기록을 사용합니다.

매 실행 첫 화면은 기본 모드이며 기본 모드의 Q는 모두 1.4입니다.
모드는 기본 모드, FPS 모드, 음악 보컬, 음악 밸런스, 영화입니다.
사용자 사운드 저장·가져오기·내보내기는 제거했습니다. 수동 조절값은 현재 실행 중에만 유지됩니다.
새 버전 첫 실행 때 이전 사용자 저장값을 삭제합니다. 설정의 진단 기록 저장은 유지됩니다.
공개 음향 자료와 첨부 제안서를 바탕으로 네 가지 모드의 핵심 대역을 강조했습니다. 기본·음악·영화 모드의 대역은 32·63·125·250·500·1000·2000·4000·8000·16000 Hz, Q 1.4입니다. 정확한 게인은 자체 설계값이며 제품별 최적 보정값은 아닙니다. 최종 튜닝은 REW 원본 데이터와 청음으로 확정하세요.
사용 방법과 검증 기록은 docs 폴더를 확인하세요.

FPS는 사용자 제공 이미지의 주파수·게인 비율을 약 46.49%로 조정했습니다. PEAK·Q 1.4를 유지하며 예상 합성 최대는 약 +5.96 dB입니다. 상세 값과 계산 한계는 [FPS 비율 조정](docs/FPS_비율_조정.md)을 확인하세요.
