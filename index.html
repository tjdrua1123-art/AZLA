⚠

Flash 저장 확인

현재 EQ 설정을 DAC의 Flash에 기록합니다. 기존에 저장된 EQ 설정을 덮어쓸 수 있으며, 저장 중 DAC를 분리하면 안 됩니다.

빠른 사용 방법

  1. Windows의 Chrome 또는 Edge에서 이 프로그램을 열고 USB DAC를 연결합니다.
  2. USB DAC 연결 버튼을 누르고 CB5100PRO가 탑재된 장치를 선택합니다.
  3. FPS(300Hz +8 dB / 3.2kHz +9 dB)·음악 모드를 선택하거나 10밴드의 주파수·게인·Q를 직접 변경합니다. 전체 출력 음량은 변경하지 않습니다.
  4. 필터 종류(PEAK·LS·HS·LP·HP)를 선택할 수 있습니다. HS는 실험용이고, LP/HP는 게인과 무관하게 필터링됩니다.
  5. REW에서 EQ OFF와 ON 응답을 TXT/CSV로 저장해 비교 창에 각각 불러올 수 있습니다.
  6. 임시 적용 (RAM)으로 테스트 후 Flash에 저장으로 비휘발성 기록 명령을 보냅니다.
  7. USB를 분리해 다시 연결한 뒤 EQ 변화가 유지되는지 청음·계측으로 확인합니다.

CB5100PRO의 제조사 확인 10밴드 지원을 기준으로 합니다. 기존 8밴드 JSON도 가져올 수 있으며 9·10번은 PEAK 0dB로 확장합니다.

프리셋 여러 개의 기기 내 동시 저장 및 하드웨어 버튼에 의한 모드 변경은 이 SDK로 검증되지 않았습니다. Flash 저장 완료는 USB 전송 완료를 뜻하며 실제 영구 보존은 재연결 시험이 필요합니다.
